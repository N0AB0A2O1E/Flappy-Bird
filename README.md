# Hi - Interactive Games Collection

A collection of fun, interactive browser-based games built with HTML5 Canvas and vanilla JavaScript.

## Games

### 🐦 Flappy Bird
A classic Flappy Bird game with beautiful themes, particle effects, and smooth animations. Navigate through pipes without hitting them. Features include:
- 50+ unique themes to choose from
- Dynamic difficulty that increases as you score
- Combo multiplier system
- Particle effects and screen shake
- Sound effects and background music

### 🎖️ Stickman Defense
A tower defense game featuring stickman soldiers defending against waves of enemies. Strategy-based gameplay with:
- Multiple unit types and upgrades
- Wave-based enemy progression
- Resource management
- Strategic placement mechanics

## Features

- **Responsive Design** - Works great on desktop, tablet, and mobile
- **Smooth Performance** - Optimized Canvas rendering with FPS counter
- **Beautiful UI** - Gradient backgrounds, particle effects, and polished animations
- **Sound Effects** - Audio feedback and background music
- **Progressive Difficulty** - Games get more challenging as you advance

## How to Play

1. Visit the [website](https://n0ab0a2o1e.github.io/Flappy-Bird/)
2. Select a game from the menu
3. Follow the in-game instructions to play

**Flappy Bird Controls:**
- Click or press Space/Arrow Up/W to flap

**Stickman Defense Controls:**
- Click to select and place units
- Use dropdowns to upgrade units

## Technologies

- HTML5 Canvas for rendering
- Vanilla JavaScript (no frameworks)
- Web Audio API for sound effects
- CSS3 animations
